# CERTICOS BOOKS 화면 명세 정리

## 유의사항

- 디자인만으로 요구사항이 명확할 경우 별도의 텍스트로 작성되어 있지 않음
- 명시되지 않은 요구사항은 지원자 개인의 판단에 따라 작업

## 디자인 시안 외 기타 화면

### 404 error 페이지

- title: 404 Not Found
- content: 페이지를 찾을 수 없습니다. 입력하신 주소가 정확한지 다시 한 번 확인해 주세요.
- [메인 페이지로 이동] 버튼
  - 클릭 시 도서 검색 페이지 이동
  - default: 활성화

### error modal

- 401
  - title: 요청이 실패했습니다.
  - content: API Key 설정을 확인해 주세요.
  - [닫기] 버튼
    - 클릭 시 modal 비활성화
    - default: 활성화
- 429
  - title: 요청이 실패했습니다.
  - content: 요청이 많아 잠시 후 다시 시도해 주세요.
  - [닫기] 버튼
    - 클릭 시 modal 비활성화
    - default: 활성화
- 5XX
  - title: 요청이 실패했습니다.
  - content: 요청 중 문제가 발생했습니다. 잠시 후 다시 시도해 주세요.
  - [닫기] 버튼
    - 클릭 시 modal 비활성화
    - default: 활성화

## 공통

### navigation

- 로고
- 도서 검색
  - 클릭 시 도서 검색 페이지 이동
- 내가 찜한 책
  - 클릭 시 내가 찜한 책 페이지 이동

## 도서 검색 페이지

- 페이지 이동 시 화면 초기화
- 초기 화면: 검색 결과 없음 화면

### 공통 요소

- 검색 필드 하단 문구: 도서 검색 결과 총 n건
  - 검색 요청 대기 중 미노출
- 도서 검색 필드
  - input
    - placeholder: 검색어를 입력하세요
    - min: 1 (trim 기준)
    - max: 100
    - default: 활성화
    - Enter 입력 시 검색 요청
      - 상세 검색 팝업의 검색 조건 select, 검색어 입력 필드 초기화
      - 검색 결과는 도서 검색 결과로 노출
  - 검색 기록
    - 최대 8개. 8개 초과 시 오래된 순으로 삭제
    - 정렬: 최신순
    - 저장: 전체 검색만 저장
    - 동일 키워드 검색 시 목록 최상단으로 이동
    - 브라우저 재시작 후에도 목록 유지 (localStorage)
    - 활성화 조건
      - input 활성화 시점에 검색 기록이 있을 경우
      - input 입력값을 모두 지웠을 경우 (input 활성화 유지 시)
    - 비활성화 조건
      - Esc 입력
      - 외곽 클릭
      - input 입력값이 생길 경우
    - list item
      - 검색 키워드
        - 클릭 시 검색 요청
          - 도서 검색 필드 Enter 입력과 동일
      - X 버튼
        - 클릭 시 검색 기록에서 삭제
        - default: 활성화
- 상세 검색 버튼
  - 클릭 시 버튼 하단에 상세 검색 팝업 노출
  - default: 활성화
- 상세 검색 팝업
  - 유의사항
    - 전체 검색과 상세 검색은 동시에 진행 불가
    - 상세 검색 요청 시 도서 검색 필드 입력값 초기화
    - 전체 검색 요청 시 상세 검색 조건 초기화
  - 비활성화 조건
    - Esc 입력
    - 팝업 외곽 클릭 (상세 검색 버튼 포함)
    - X 버튼 클릭
    - 검색하기 버튼 클릭
  - 비활성화 시 검색 조건 select, 검색어 입력 필드 초기화
  - 검색 조건 select dropdown (target)
    - placeholder: 검색 조건
    - options: 제목 / 저자 / 출판사
    - default: 선택 없음
  - 검색어 입력 필드
    - input
      - placeholder: 검색어 입력
      - min: 1 (trim 기준)
      - max: 100
      - default: 활성화
      - Enter 입력 시 검색 요청 없음
  - 검색하기 버튼
    - 클릭 시 상세 검색 요청
      - 도서 검색 필드 입력값 초기화
      - 검색 결과는 상세 검색 결과로 노출
    - default: 비활성화
    - 활성화 조건: 검색 조건 select 선택, 검색어 입력 필드 입력값 1자 이상
  - X 버튼
    - 클릭 시 팝업 비활성화
    - default: 활성화
- 검색 요청 대기 중 로딩 화면 노출

### 검색 결과 없음

- 문구: 검색된 결과가 없습니다.

### 검색 결과 있음

- 한 번에 10개씩 로드 (무한 스크롤)
  - 다음 목록 요청 대기 중 목록 하단에 로딩 UI 노출
  - 최대 50페이지 (500건) 조회 가능
  - end of scroll
    - 문구: 결과를 모두 불러왔습니다.
    - 50페이지까지 불러왔을 때 총 검색 결과가 불러온 개수보다 많을 경우
      - 문구: 검색 결과는 최대 500건까지 확인할 수 있습니다.
- 책 컴포넌트
  - ID (찜 목록 식별용): 책 제목 + ISBN (공백 문자 모두 제거)
    - ISBN 값이 2개일 경우 공백 기준 첫 번째 값 사용
  - 상세보기 accordion 여러 개 동시 활성화 가능
  - 책 이미지
    - 이미지 없을 경우 대체 컴포넌트 (gray box)
    - 찜하기 버튼
      - 찜 목록에 있을 경우 filled, 없을 경우 empty
      - filled 상태에서 클릭 시 찜하기 해제
      - empty 상태에서 클릭 시 찜하기
  - 책 제목
    - 값 없을 경우 "-"
  - 저자
    - 값 없을 경우 "-"
    - 여러 명일 경우 ", "로 구분
    - 길어질 경우 ellipsis
  - 금액 (실제 결제 금액)
    - sale_price > 0일 경우 sale_price, 아닐 경우 price
    - 천 단위 "," 표기
    - 값 없을 경우 "-"
  - 구매하기 버튼
    - 클릭 시 새 탭에서 도서 상세 링크 (API 제공 url) 이동
    - default: 활성화
  - 상세보기 버튼 (accordion)
    - 클릭 시 상세 정보 노출
    - default: 활성화
- 책 상세 정보
  - 책 이미지
    - 상기 명세와 동일
  - 책 제목
    - 상기 명세와 동일
  - 저자
    - 상기 명세와 동일
  - 책 소개
    - 값 없을 경우 "-"
  - 원가 (price)
    - 천 단위 "," 표기
    - 값 없을 경우 "-"
    - 할인가 노출 시 취소선 표시
  - 할인가 (sale_price)
    - 천 단위 "," 표기
    - 노출 조건: sale_price > 0
  - 구매하기 버튼
    - 상기 명세와 동일
  - 상세보기 버튼
    - 클릭 시 상세 정보 비활성화
    - default: 활성화

## 내가 찜한 책

**유의사항**

- 찜하기 버튼 클릭 시점의 데이터를 저장하므로 API 결과와 데이터가 다를 수 있음
- 브라우저 재시작 후에도 목록 유지

- 저장: localStorage
- 목록 정렬: 최근 찜한 순

### 공통

- title: 내가 찜한 책
- 문구: 찜한 책 총 n건

### 책 없음

- 문구: 찜한 책이 없습니다.

### 책 있음

- 한 번에 10개씩 로드 (무한 스크롤)
  - end of scroll
    - 문구: 결과를 모두 불러왔습니다.
- 책 컴포넌트
  - 상기 명세와 동일
  - 찜하기 해제 시 목록에서 바로 제거
